# Plus X 공개 작업에서 찾은 BX 설계 원리

> B05 · BX · 상태: 리서치 완료 · 갱신: 2026-11-10

공개 프로젝트 146건, 핵심 심층 사례 18건의 확인 범위와 한계를 기록하고 농작물 서비스에 적용할 설계 질문을 정리합니다.

## 146개 공개 프로젝트와 18개 심층 사례

2026년 11월 10일 Plus X 공식 Experience 카탈로그의 공개 프로젝트 146건을 조사 범위로 정했습니다. 비공개 의뢰, 삭제된 과거 작업, 모든 이미지와 영상 프레임을 포함한 전체 역사라는 뜻은 아닙니다.

146건의 개별 분석에 더해 관련성이 높은 18건을 문제·전략·접점·농작물 서비스의 적용 조건으로 심층 분석했습니다. 데스크톱·모바일 중복은 한 프로젝트로 처리하고, 동일 고객의 별도 프로젝트는 각각 유지했습니다.

| 공식 분류 | 건수 | 해석 |
| --- | --- | --- |
| BX 전용 | 82 | 브랜드 전략·아이덴티티·패키지 등 |
| UX 전용 | 55 | 서비스 구조·탐색·구매·운영 경험 등 |
| BX와 UX 동시 | 5 | 두 범주에 등록된 프로젝트 |
| 별도 분류 없음 | 4 | 카탈로그 all에만 등록된 프로젝트 |

> **읽는 기준**
> 아래의 공식 설명은 제작사가 밝힌 문제와 설계 의도입니다. 농작물 서비스 적용은 우리의 해석이며 실제 고객 조사, 품질 검증, 브랜드 성과를 의미하지 않습니다.

## 무엇을 확인했고 무엇을 확인하지 않았는가

146건 모두 공개 상세 자료에 접근했습니다. 본문·설명형 대체텍스트에 근거한 분석 132건, 짧은 설명·이미지 중심으로 제한적인 분석 12건, 전략 판단 근거 부족 2건으로 구분했습니다.

근거가 부족한 두 건은 Beauty of Joseon과 British Council Words입니다. Beauty of Joseon은 별도의 Plus X 공식 회고로 심층 분석을 보강했습니다. 개별 아카이브의 근거 부족과 추가 자료에 의한 보강을 함께 기록합니다.

BTS, YG, A NORMAL, SYSTEM, Channel A, Plus X Identity, 29CM, Hyundai Card Purple, Simply Juice의 정적 화면 또는 이미지를 확인했습니다. 확인 범위는 9개 사례의 일부 정적 자료이며, 각 사례의 모든 디자인을 시각 검수한 결과가 아닙니다.

영상, 실물, 현재 서비스의 실제 동작, 사업 성과는 검증하지 않았습니다. 제목·메타데이터의 템플릿 오류는 본문과 대조했습니다. 공개 페이지 접근 성공을 실제 서비스의 효과나 현재 운영 상태의 증거로 취급하지 않습니다.

| 확인 수준 | 건수 | 해석 |
| --- | --- | --- |
| 본문·설명형 대체텍스트 | 132 | 공식 설명으로 프로젝트의 문제와 설계 원리를 요약 |
| 짧은 설명·이미지 중심 | 12 | 설명된 범위만 제한적으로 분석 |
| 전략 판단 근거 부족 | 2 | 제목이나 익숙한 브랜드 이미지로 내용을 보충하지 않음 |

## 의미를 형태와 행동으로 연결하는 구조

Plus X Identity 공식 사례는 고객 브랜드의 근본 가치에서 경험을 설계하는 태도를 설명합니다. 여러 사례를 비교하면 문제 → 의미 → 원칙 → 체계 → 행동이라는 연결 구조를 읽을 수 있습니다. 이 구조는 이번 연구의 해석이며 Plus X가 공식 명명한 단일 방법론이 아닙니다.

농가의 선별 도구, 수확 판단, 식감, 손질 동작, 계절 변화 가운데 실제로 중요한 단서를 찾아 여러 접점에서 반복 가능한 규칙으로 발전시킵니다. 농가의 사실이 확인되기 전에 다른 브랜드의 핵심 형태를 가져오지 않습니다.

| 설계 단계 | 실제 사례에서 확인한 연결 | 우리 프로젝트의 산출물 |
| --- | --- | --- |
| 1. 문제 | YG: 사업 확장에 대응할 체계 | 농가의 강점·판매 제약·고객의 선택 불안 |
| 2. 의미 | BTS: 성장 서사에서 문 모티프 도출 | 브랜드가 고객에게 맡을 역할 |
| 3. 원칙 | Simply Juice: 브랜드 성격을 디자인 원칙으로 번역 | 정확성·절제·배려의 판단 기준 |
| 4. 체계 | 29CM: 다양한 접점을 위한 조합 규칙 | 품목이 바뀌어도 유지되는 정보·표현 규칙 |
| 5. 행동 | Purple: 꺼내기와 정보 탐색까지 설계 | 선택·개봉·보관·먹기·문제 해결의 경험 |

## 식재료의 특성을 읽을 수 있는 정보로

식품에 가까운 사례는 재료와 생산의 특성을 어떤 표현 규칙으로 바꿨는지 살펴봅니다. 다음 표의 가운데 열은 공식 사례의 설명이고, 마지막 열은 이번 농작물 서비스에 대한 적용 제안입니다.

무엇인가 → 왜 골랐는가 → 어떻게 즐기는가 → 어떤 상태로 받는가의 순서를 정보 구조의 후보로 둡니다. 자연스러운 디자인 인상은 실제 인증이나 품질의 증명이 아닙니다.

| 공식 사례 | 확인한 설계 | 농작물 서비스 적용 제안 |
| --- | --- | --- |
| Simply Juice | 과일 상자 모티프와 절제된 색으로 재료를 중심에 둔다. | 상품의 색과 상태를 보여주고, 브랜드는 선별 이유를 명료하게 전달한다. |
| 우리술방 | 술의 분류·재료·제조 과정을 병과 라벨 규칙으로 연결한다. | 품종·농가·수확·취급 정보의 공통 라벨 체계를 만든다. |
| Archiveat | 요리 동작과 소리를 시각 언어로 전개한다. | 식감과 손질 동작을 사진·콘텐츠·사용 안내의 단서로 삼는다. |

## 품격을 선택과 사용의 디테일로

29CM, Hyundai Card Purple, Plus X Object는 선택·꺼내기·정보 탐색·제품 사용 맥락을 함께 검토하게 합니다. 감각적인 인상과 실제 사용의 편안함을 별도로 확인해야 합니다.

고객이 편리하다고 느끼는 이유와 갖고 싶어 하는 이유를 각각 검증합니다. 브랜드 사이트의 설명, 거래 채널의 옵션·가격·출고 정보, Storybook의 내부 근거가 서로 일치하도록 설계하는 데 참고합니다.

| 공식 사례 | 확인한 설계 | 농작물 서비스 적용 제안 |
| --- | --- | --- |
| 29CM | 선택을 돕는 미션에서 확장 가능한 디자인 원칙을 도출한다. | 추천의 이유와 품목 탐색 방식을 일관되게 정리한다. |
| Hyundai Card Purple | 구성물 배열·꺼내는 구조·혜택 정보의 위계를 함께 설계한다. | 상자 개봉부터 품목에 맞는 보관까지 손이 덜 가도록 구성한다. |
| Plus X Object | 제품 사용 맥락과 자사몰의 고유 정보 역할을 다룬다. | 브랜드 사이트를 선별·농가·먹는 방법의 원본 정보로 운영한다. |

## 품목이 바뀌어도 유지할 기준

YG, Cleanlab, Konny의 공식 사례는 사업·상품·매체의 확장에 맞춰 브랜드 체계를 정리한 과정을 설명합니다. 확장 가능성을 설계하는 것과 출시부터 여러 품목을 운영하는 것은 별도의 판단입니다.

| 공식 사례 | 확인한 설계 | 농작물 서비스 적용 제안 |
| --- | --- | --- |
| YG | 핵심 가치를 서체·서브브랜드·내부 가이드로 확장한다. | 농가·포장·콘텐츠 담당자가 같은 판단 기준을 사용한다. |
| Cleanlab | 특정 제품의 인지에서 여러 생활 영역을 아우르는 정체성으로 확장한다. | 브랜드는 선별 태도, 상품은 작물명과 용도로 구분한다. |
| Konny | 기존 의미를 계승하면서 제품과 매체 확장에 맞게 심벌을 정리한다. | 작은 라벨·흑백 인쇄·모바일에서도 작동하는 자산을 만든다. |

## 고유한 의미에서 반복 가능한 표현으로

BTS는 서사의 문을 펼침과 빛의 활용으로, A NORMAL은 향과 감각을 명명·탐색·그래픽으로, SYSTEM은 제작 태도와 기록을 브랜드 맥락으로 연결합니다. 각 표현의 표면보다 의미가 여러 접점으로 전개되는 원리를 참고합니다.

BTS의 공개 응용물에는 아이덴티티 활용 예시가 포함됩니다. 이를 모두 실제 출시된 제품으로 취급하지 않습니다. 선별 노트도 실제 차이를 전달하는 장치의 후보이며 형식 자체가 경쟁력으로 검증된 것은 아닙니다.

| 공식 사례 | 확인한 설계 | 농작물 서비스 적용 제안 |
| --- | --- | --- |
| BTS | 문 모티프를 펼침·빛·디지털 동작의 활용 예시로 확장한다. | 선별·개봉·손질의 실제 행동에서 표현 원리를 찾는다. |
| A NORMAL | 향과 감각을 명명·제품 탐색·그래픽 변형으로 연결한다. | 작물명과 사용 상황을 함께 탐색하는 구조를 검증한다. |
| SYSTEM | 제품을 만드는 태도와 축적된 기록을 브랜드 맥락으로 다룬다. | 농가의 수확 판단과 취급 기록을 지속적으로 축적한다. |

## 조직·지역·탐색까지 이어지는 태도

다음 여섯 사례는 브랜드의 태도가 조직의 행동, 지역성, 탐색과 상위 의미에서도 이어지는지 묻게 합니다. 사례의 디자인 의도를 이번 서비스의 확정 약속으로 옮기지 않습니다.

146개 개별 분석과 18개 심층 분석은 아래 연결된 산출물에서 확인할 수 있습니다. 기존 국내외 35개 농작물 서비스 비교 리서치는 B01에 유지하며, 두 조사를 서로 다른 목적과 범위의 자료로 사용합니다.

| 사례 | 관찰한 설계 원리 | 우리의 적용 질문 |
| --- | --- | --- |
| Channel A | 내부 구성원과 이용자에게 연결되는 브랜드 약속 | 농가가 지킬 행동이 고객의 이익으로 설명되는가? |
| Deepondé | 브랜드 태도를 이름과 층·깊이의 표현으로 연결 | 우리의 판단 태도에서 고유 원리를 만들 수 있는가? |
| Beauty of Joseon | 전통 원료를 상위 브랜드 가치로 재해석 | 농가의 지역성이 오늘의 식사에 어떤 의미인가? |
| G9 | 목적이 다른 사용자의 탐색과 콘텐츠 운영을 구분 | 처음 고르는 고객과 다시 사는 고객을 돕는가? |
| Tetrapod | 지역 모티프를 잔·라벨·도구·공간으로 확장 | 지역의 실제 특성이 사용의 이익으로 이어지는가? |
| Plus X Identity | 고객 브랜드의 본질을 바탕으로 경험 설계 | 대행사의 스타일보다 우리 농가의 근거가 먼저인가? |
