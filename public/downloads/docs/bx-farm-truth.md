# 농가의 사실·품질 증거·검증 순서

> OPS04 · 운영 · 상태: 검토 중 · 갱신: 2026-11-10

농가 인터뷰와 샘플, 품질·포장·출고의 실제 조건을 BX 판단에 연결하고 필요한 역할과 다음 단계의 진입 조건을 정리합니다.

## 먼저 확보할 네 가지 입력

다음 BX 결정을 위한 첫 입력은 농가의 실제 차이입니다. 후보 작물, 농가의 강점, 가능한 선별·포장 수준, 안정적인 출하 범위를 확인합니다. 답변을 바로 홍보 문장으로 바꾸지 않고 기록·관찰·샘플에 연결합니다.

이 문서는 기존 OPS01 농가 확인 항목을 BX 품질 증거와 의사결정에 연결하는 검토안입니다. 작물·품종·공급량·인증·가격·담당자·운영 정책이 확정됐다는 뜻이 아닙니다.

> **현재 필요한 자료**
> 후보 작물 / 실제 농가의 강점 / 가능한 선별·포장 수준 / 안정적인 출하 범위

## 농가 대표에게 묻고 실물·기록으로 확인한다

질문마다 답변 주체, 확인 날짜, 자료 또는 실물 관찰, 공개 가능한 범위를 함께 기록합니다. 생산자가 공개에 동의한 정보와 내부 검토용 자료를 구분합니다.

| 질문 | 받을 자료 또는 관찰 |
| --- | --- |
| 무엇을, 언제, 어느 정도 생산할 수 있는가? | 작물·품종 목록, 계절별 출하 범위, 일정 변동 요인 |
| 같은 작물 중 좋은 것을 어떻게 구별하는가? | 실물 비교와 선별 기준, 제외하는 상태의 예 |
| 그 차이는 고객의 어느 식사에서 드러나는가? | 생식·가열 등 사용 비교, 농가의 추천 이유 |
| 누가 선별하고 어떤 기록을 남기는가? | 작업 흐름, 담당자, 반복 가능한 기록 방식 |
| 현재 어디까지 손질·포장할 수 있는가? | 작업대·재료·도구·소요 시간·포장 샘플 |
| 배송 이후 상태는 어떻게 달라지는가? | 실제 배송 관찰과 손상·변화 이력 |
| 브랜드가 공개해도 되는 생산 정보는 무엇인가? | 농가 동의 범위, 확인 가능한 자료 |
| 공급이 부족하거나 품질이 안 맞으면 어떻게 하는가? | 대체·취소·출고 보류 등 현실적인 처리 방식 |

## 품질 기준·측정·기록·예외 처리를 함께 정한다

엄선이라는 표현을 사용하려면 어떤 기준으로 선택하고 기준에 미치지 못할 때 어떻게 처리하는지 정의해야 합니다. 다음 항목은 수집할 증거이며 현재 확인된 품질 보증이 아닙니다.

| 증거 영역 | 정의할 항목 | 현재 상태 |
| --- | --- | --- |
| 품목과 용도 | 정확한 작물·품종·목표 식사 상황 | 미확정 |
| 감각과 규격 | 용도에 맞는 식감·크기·상태의 기준과 측정 방법 | 농가·샘플 확인 필요 |
| 재배·수확 | 실제 제공 가능한 농가·수확 기록과 확인 주체 | 농가 자료 필요 |
| 선별·포장 | 허용 상태, 검사 빈도, 포장 방법, 제외 처리 | 운영 합의 필요 |
| 운송·도착 | 손상·상태 변화·출고와 수령 변동 | 포장·배송 시험 필요 |
| 사용 경험 | 보관 안내, 손질·조리 시간, 남는 양 | 사용 관찰 필요 |
| 문제 해결 | 접수 경로, 확인 항목, 대응 책임, 개선 반영 | 서비스 정책 필요 |

> **검증 전에는 빈칸을 유지**
> 기준·측정법·책임자·예외 처리가 정해진 뒤 고객 문구를 확정합니다. 임의의 맛 점수·품질 등급·시간 보증으로 수치화하지 않습니다.

## 기본 품질과 선별 취향, 기록 단위를 구분한다

모든 상품이 지켜야 할 도착 상태와 특정 요리에 맞춰 선택하는 식감은 다른 기준입니다. 기본적인 품질 충족과 브랜드만의 선별 취향을 각각 검토합니다.

선별 노트의 기록 단위는 품목·농가·출고 운영을 확인한 뒤 정합니다. 수확별 기록과 배치 번호는 실제 차이를 지속적으로 확인·관리할 수 있을 때 도입합니다.

수확·포장·출고 날짜를 혼동하지 않고 보관 방식은 실제 품목에 맞게 확인합니다. 검사 빈도, 포장 작업량, 정보 갱신 책임이 농가가 반복 수행할 수 있는 수준인지 함께 봅니다.

## 필요한 역량과 책임 산출물

직군은 필요한 역량을 뜻합니다. 초기에는 한 사람이 여러 역할을 맡을 수 있지만 중요한 판단의 책임은 실제 담당자로 지정해야 합니다.

기존 계획의 태훈은 브랜드·패키지·사이트·채널·마케팅의 조율 역할로 연결할 수 있습니다. 모든 전문 판단까지 단독 수행한다고 가정하지 않습니다. 농가 대표는 생산·선별의 가능 범위를, 사업 책임자는 고객에게 약속할 범위를 함께 확인해야 합니다.

담당자·외주 여부·예산·일정은 미확정입니다. 아래 목록은 채용 인원이나 계약 범위의 확정안이 아닙니다.

| 역할 | 핵심 역량 | 책임 산출물 |
| --- | --- | --- |
| 사업·상품 책임자 | 고객 문제, 상품 구성, 원가·판매 조건 판단 | 첫 상품 범위와 브랜드 약속의 현실성 |
| 농가 생산 책임자 | 재배·수확·상태 판정, 생산 기록 | 농가 사실 자료와 품목별 선별 기준 |
| 품질·포장 운영 | 검수, 포장 작업, 배송 시험, 문제 원인 분석 | 출고 기준과 작업·예외 처리 기록 |
| BX 전략·콘텐츠 | 포지셔닝, 정보 구조, 언어·증거 편집 | 브랜드 원칙과 선별 노트 체계 |
| 시각·패키지 디자인 | 아이덴티티 체계, 인쇄·소재·구조 설계 | 재현 가능한 시각 자산과 패키지 |
| UX·프런트엔드 | 사용 흐름, 접근성, 컴포넌트·콘텐츠 구현 | 브랜드 사이트·Storybook·구매 연결 |
| CRM·CS·마케팅 | 안내, 문의 처리, 실험, 성과 해석 | 구매 전후 커뮤니케이션과 개선 기록 |

## 앞 단계의 근거가 다음 결정을 지지하도록

농가의 사실 → 고객과 약속 → 언어와 이름 → 시각 원리 → 실제 경험 → 작은 판매 검증 순서로 검토합니다. 각 단계는 완료해야 할 산출물과 다음 단계로 갈 조건을 함께 둡니다.

아래는 실행 순서의 제안입니다. 일정은 농가 접근성·품목·출하 시기·담당 인력에 따라 달라지므로 특정 주차·비용·전환율을 확정하지 않습니다.

| 순서 | 작업과 산출물 | 다음 단계로 갈 조건 |
| --- | --- | --- |
| 1. 농가의 사실 | 현장·샘플·선별·포장·공급 자료 | 반복 가능한 차이와 제약을 문서로 설명 |
| 2. 고객과 약속 | 우선 고객, 식사 상황, BX 정의 v0.2 | 고객 문제와 농가의 강점이 연결됨 |
| 3. 언어와 이름 | 포지셔닝 문장, 네이밍 후보, 말투 | 의미·발음·혼동·활용 적합성을 평가 |
| 4. 시각 원리 | 복수 방향의 표현과 대표 접점 시안 | 농가의 근거·식별성·제작성 기준으로 비교 |
| 5. 실제 경험 | 상품 상세, 포장, 안내, 문의 흐름 시제품 | 선택·수령·사용 전 과정에서 작동 |
| 6. 작은 판매 검증 | 유료 구매·사용·재구매 이유와 운영 기록 | 약속·품질·운영 비용의 지속 가능성을 확인 |

## 초기 관찰과 v0.2로 넘어갈 조건

먼저 6~8명 정도의 목적 있는 인터뷰·사용 관찰로 이해되지 않는 부분을 찾는 방안을 제안합니다. 이는 통계적인 시장 검증이 아닙니다. 표본·성공 기준·예산은 실행 전에 별도로 정합니다.

이후 실제 결제와 반복 배송으로 행동과 운영 재현성을 검토합니다. 고객의 호감, 사용상의 차이, 지불 의사, 품질 재현성과 운영 비용을 함께 확인합니다.

농가의 네 가지 입력과 첫 고객 근거가 확보되면 BX v0.2에서 고객 가설과 첫 상품 경로를 좁히고 네이밍·시각 방향의 브리프를 작성합니다. 단계별 판단은 OPS05 결정 기록에 연결합니다.
