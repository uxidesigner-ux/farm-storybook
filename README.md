# FIELDNOTES — Codex 인계용 Storybook 초안

이 저장소는 **미완성 인계본**입니다. 작업 지시와 정확한 현재 상태는 [CODEX_TASK.md](CODEX_TASK.md)를 먼저 읽으세요.

18개 가이드 문서, 35개 벤치마크, 공통 UI 초안과 6개 컴포넌트·18개 스토리가 준비돼 있습니다. 페이지 4개와 CSS, 검증 스크립트, CI·배포 workflow는 구현해야 합니다. 전체 빌드·브라우저 검증·GitHub 연결·푸시·외부 배포는 완료되지 않았습니다.

FIELDNOTES는 문서 공간의 임시 작업명이며, 실제 농산물 브랜드는 미정입니다.

ZIP은 node_modules와 Git 메타데이터를 포함하지 않습니다. 새 환경에서 번호가 있는 작업 브랜치를 만들고 npm ci로 의존성을 복원하세요. main에는 머지·푸시하지 않으며, dev 대상 반영도 사용자 승인 후 수행합니다.
