# 실험과 성과 측정

> M03 · 마케팅 · 상태: 초안 · 갱신: 2026-11-10

유입과 실제 구매, 식재료 사용과 재구매를 나눠 보고 메시지·상품을 개선합니다.

## 하나의 실험은 하나의 질문에서

첫 실험은 고객이 무엇 때문에 선택하는지 확인하는 데 집중합니다. 메시지, 상품 구성, 가격과 배송 조건을 한꺼번에 바꾸면 반응의 이유를 해석하기 어렵습니다. 초기 표본이 작을 때는 수치와 실제 사용자 맥락을 함께 읽습니다.

## 단계별로 확인할 지표

목표값은 아직 정하지 않았습니다. 실제 채널과 수집 가능한 데이터, 초기 관찰값을 확인한 뒤 판단 기준을 설정합니다.

| 단계 | 확인할 행동 | 해석 시 구분 |
| --- | --- | --- |
| 발견 | 문서·상품 유입 · 관심 콘텐츠 | 노출과 실제 방문 |
| 비교 | 상품 조회 · 정보 탐색 · 문의 | 호기심과 구매 준비 |
| 구매 | 구매 이동 · 주문 · 결제 | 외부 이동과 실제 결제 완료 |
| 사용 | 첫 사용 · 소비량 · 잔량 | 레시피 조회와 식재료 소비 |
| 반복 | 재주문 · 구매 주기 · 이탈 이유 | 할인 반응과 지속 구매 |
| 손익 | 주문당 비용 · 공헌이익 | 매출과 남는 이익 |

## 실험 기록의 형식

가설, 대상, 노출 조건, 변경 항목, 기간, 결과, 한계와 다음 결정을 남깁니다. 성공·실패를 같은 기준으로 기록하고, 외부 채널에서 실제 결제 여부를 확인할 수 없으면 추정 전환으로 표시합니다.

## 좋은 지표를 잘못 읽지 않기

높은 클릭률은 상품의 차이나 반복 구매를 입증하지 않습니다. 낮은 판매량도 메시지 하나의 문제로 단정하지 않습니다. 품절·배송 지역·가격·유입 대상과 같은 조건을 함께 검토합니다.

- 신규 고객과 기존 고객을 가능한 범위에서 구분합니다.
- 체험·할인 주문과 정상 가격 주문을 구분합니다.
- 한 번의 좋은 수확 결과를 연중 품질로 확대하지 않습니다.
- 실제 소비 주기가 지난 뒤 재구매를 관찰합니다.
