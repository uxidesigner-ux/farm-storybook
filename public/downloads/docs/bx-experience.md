# 고객 경험 원칙

> B04 · BX · 상태: 초안 · 갱신: 2026-11-10

발견·주문·개봉·사용·재구매가 하나의 약속으로 이어지도록 접점을 정의합니다.

## 실제 사용까지 이어지는 약속

브랜드가 약속하는 가치는 주문 전 설명과 도착한 상품, 실제 식사에서 연결돼야 합니다. 이 문서는 그 연결을 설계하는 초안입니다. 어떤 접점이 재구매에 가장 큰 영향을 미치는지는 아직 검증되지 않았습니다.

## 접점별로 답할 질문

각 접점은 고객이 다음 행동을 이해하고 실행할 수 있게 구성합니다.

| 순간 | 고객의 질문 | 필요한 경험 |
| --- | --- | --- |
| 발견 | 왜 이 상품인가? | 한 문장 가치 · 실제 농가와 작물의 근거 |
| 비교 | 내 식사에 맞는가? | 맛 · 분량 · 용도 · 손질 상태 · 총가격 |
| 주문 대기 | 언제 무엇이 오는가? | 출고 일정 · 구성 · 대체 기준 |
| 개봉·보관 | 지금 무엇부터 해야 하나? | 도착 상태 · 보관 · 먼저 먹을 순서 |
| 첫 사용·잔량 | 끝까지 잘 쓸 수 있는가? | 첫 사용 방법 · 남은 재료 활용 |
| 문제·재구매 | 믿고 다시 살 수 있는가? | 접수 · 해결 기준 · 재주문 동선 |

## 사용을 돕는 정보의 분량

처음부터 많은 레시피를 제공하기보다 첫 사용 방법 하나와 추가 활용을 간결하게 시험합니다. 세척·손질·보관 안내는 실제 출고 상태와 맞아야 합니다. 안내만으로 해결되지 않으면 용량·구성·포장부터 수정합니다.

## 관찰할 행동

콘텐츠 조회와 실제 식재료 사용을 분리해 확인합니다. 고객의 기록 부담을 줄이면서 잔량과 사용 맥락을 파악합니다.

- 개봉한 시점과 첫 사용까지 걸린 시간
- 사용한 요리와 횟수, 실제로 먹은 양
- 남은 양과 보관·폐기 이유
- 다시 구매하게 되는 상황과 망설임
