# 선별의 기준이, 일상의 취향이 되다


## 프리미엄 농작물 서비스 BX Foundation v0.1


작성일: 2026-11-10 · 상태: 전략 초안 · 품목과 브랜드명 미확정


이 문서의 고객 행동, 품질 약속, 표현 방향은 검증할 제안입니다. 실제 제공 범위와 책임자가 확정되기 전에는 소비자용 운영 약속으로 게시하지 않습니다.


## 01 / STRATEGIC ANSWER

프리미엄은 선택의 이유를 경험으로 입증해야 한다

다섯 키워드는 브랜드가 지향하는 상태다. 브랜드 전략은 그 상태를 만드는 선택 기준, 고객 행동, 운영 책임까지 정의해야 한다.

> 첫 전략 가설: 선별의 기준이, 일상의 취향이 되다.

이 브랜드의 역할을 “좋은 농작물을 고르는 판단과, 선택한 농작물을 잘 즐기는 방법을 함께 제공하는 서비스”로 제안한다. 고객에게 남길 감정은 “내 선택에는 이유가 있다. 내 일상이 세심하게 다뤄진다”이다.

| 판단 | 이번 단계의 결정 |
| --- | --- |
| 브랜드의 중심 | 특정 작물의 형태보다 선별·취급·사용을 책임지는 태도를 중심에 둔다. |
| 프리미엄의 근거 | 품종·상태·용도·취급 등 실제로 설명하고 반복할 수 있는 차이를 찾는다. |
| 고객 경험 | 구매 때의 확신, 받을 때의 정돈감, 먹을 때의 만족, 문제가 생겼을 때의 신뢰를 연결한다. |
| 이번 산출물의 지위 | 전략 초안 v0.1. 품목·타깃·가격·이름·로고·품질 기준의 최종 확정본은 아니다. |

### 첫 번째 사업 판단

확장 가능한 마스터브랜드와 좁은 첫 상품 제안은 함께 갈 수 있다. 치커리·셀러리 등 한 작물에 이름을 묶지 않되, 출시 시에는 누구의 어떤 식사 상황을 해결할지 먼저 좁힌다. 선행 리서치에서 확인한 보편적 메시지에 더해 우리 농가만의 반복 가능한 증거가 필요하다. [S21]

*이 문서에서 “제안·가설·검증”으로 표시한 내용은 연구자의 전략 판단이다. 실제 고객 인터뷰나 농가 실측 결과를 의미하지 않는다.*

### 확인 수준을 나누어 기록한다

146건 모두 공개 상세 자료에 접근했다. 본문·설명형 대체텍스트에 근거한 분석 132건, 짧은 설명·이미지 중심으로 제한적인 분석 12건, 전략 판단 근거 부족 2건으로 구분했다. 부족한 두 건은 Beauty of Joseon과 British Council Words이며, 전자는 별도 공식 회고로 심층 분석을 보강했다. 페이지 접근 성공은 전체 디자인을 시각 검수했다는 뜻이 아니다.

18건은 문제·전략·접점·적용 조건을 별도로 분석했다. 이 중 BTS, YG, A NORMAL, SYSTEM, Channel A, Plus X Identity, 29CM, Purple, Simply Juice의 정적 이미지 또는 화면을 확인했다. 영상, 실물, 현재 서비스의 실제 동작과 사업 성과는 검증하지 않았다.

*수집일 2026-11-10. 데스크톱·모바일 중복은 한 프로젝트로 처리하고, 동일 고객의 별도 프로젝트는 각각 유지했다. 제목·메타데이터의 템플릿 오류는 본문과 대조해 별도 표기했다.*

### 전이해야 할 것

하나의 생각을 형태, 말, 정보의 순서, 고객의 동작, 내부 운영으로 번역하는 연결 구조다. 이 표는 여러 사례의 비교에서 도출한 해석이며, Plus X가 공식 명명한 단일 방법론은 아니다.

### 독자성을 만드는 조건

우리 농가의 관찰 가능한 특성에서 출발해야 한다. 선별 도구, 수확 판단, 식감, 손질 동작, 계절 변화 중 실제로 중요한 단서를 찾고, 이를 여러 접점에서 반복 가능한 규칙으로 만든다. 단서가 확인되기 전에 문·과일 상자·정사각형 같은 다른 브랜드의 핵심 형태를 가져오지 않는다.

> 제안하는 정보 순서: 무엇인가 → 왜 골랐는가 → 어떻게 즐기는가 → 어떤 상태로 받는가.

*사례의 디자인 의도는 현재 상품 품질·인증·판매 성과의 증명이 아니다. 오가닉한 디자인 인상과 실제 인증도 구분한다.*

### 고객이 체감할 품격의 정의

가격·중량·손질 상태·배송 일정이 분명하고, 열자마자 무엇부터 해야 하는지 알 수 있으며, 도움이 필요할 때 같은 이야기를 반복하지 않는 경험이다. 여기에 고르고 차리고 즐기는 순간의 감각적 만족이 더해져야 한다. 편리하다고 느끼는 이유와 갖고 싶어 하는 이유를 각각 검증한다.

### 채널에 대한 함의

브랜드 사이트, 거래 채널, Storybook은 역할을 나눈다. 고객에게 설명할 원본 정보와 주문 정보는 서로 일치해야 한다. 특정 플랫폼의 결제·재고·배송 연동 가능성은 별도 기술 확인 항목이며, BX 문서에서 완료된 기능으로 선언하지 않는다.

### 첫 시그니처 후보: 선별 노트

*BTS의 공개 응용물에는 활용 예시가 포함된다. 본 보고서는 이를 전부 실제 출시된 제품으로 취급하지 않는다.*

> 선별 노트 = 이번 농작물이 선택된 이유 + 고객이 잘 즐기는 방법.

| 앞면의 핵심 정보 | 작성 규칙 |
| --- | --- |
| 무엇인가 | 확정된 품목·품종·규격. 익숙한 이름과 설명을 우선한다. |
| 누가 길렀는가 | 확인된 농가·지역과 생산자가 공개에 동의한 내용. |

| 왜 골랐는가 | 해당 배치에서 확인한 선택 이유 한 문장. 근거 없는 최상급은 제외한다. |
| 어떻게 즐기는가 | 검증한 보관·손질·사용 안내를 짧게 제공한다. |

### 문장 템플릿

“이번 [품목]은 [용도]에 맞는 [확인한 특성]을 기준으로 골랐습니다. [검증한 사용 방법]으로 즐겨보세요.” 대괄호는 실제 자료로 채우기 전까지 내부 초안에서만 사용한다.

### 정보와 시각의 운영

라벨·상품 상세·출고 안내가 같은 기록을 참조하도록 한다. 상세 이력은 링크로 확장하되 기본 보관과 상품 식별 정보는 종이 또는 제품 표면에서 바로 읽을 수 있게 한다. 맛 점수나 배치 번호는 실제 기준과 관리 체계가 있을 때만 도입한다.

*선별 노트는 실제 차이를 전달하는 장치다. 기록 형식 자체를 독자적 경쟁력으로 확정하지 않는다. 후보 작물에 가안 적용 후 이해도·작성 부담·정보 유지 가능성을 확인한다.*

| 절제해서 정돈한다 | 여백과 일정한 정렬, 제한된 장식, 가격·중량·일정의 높은 가독성 | 브랜드 인상과 구매 정보가 함께 읽히는가? |
| 생명력을 남긴다 | 농작물 고유의 색·표면·계절 변화, 실제 손질과 식사 장면 | 비슷한 웰니스 브랜드와 구별할 고유 단서가 있는가? |

### 고정할 것과 바꿀 것

브랜드명·기본 정보 구조·말투·선별 근거의 표기 규칙은 고정한다. 작물 사진·농가 기록·계절별 콘텐츠는 변주한다. 색은 품목 구분을 돕되, 같은 색이 서로 다른 의미로 쓰이지 않게 역할을 정의한다.

### 실제 제작 조건

작은 라벨, 흑백 출력, 모바일 화면, 습기와 마찰이 있는 포장 환경에서 확인한다. 농가에서 반복 출력·부착할 수 있는지, 사람이 바뀌어도 같은 결과가 나오는지 함께 검토한다.

*본 보고서의 색과 레이아웃은 자료 편집을 위한 선택이다. 향후 브랜드 CI나 패키지 시안으로 확정한 것이 아니다.*


## 17 / CREATIVE TERRITORIES

첫 표현 방향은 “선별된 식탁”을 제안한다

기능적 신뢰에 감각적 매력을 더한다. 아래 이름은 비교를 위한 콘셉트 이름이며, 실제 브랜드 네이밍 후보나 확정 디자인은 아니다.

| 방향 | 고객이 기대할 감정 | 표현의 출발점과 조건 |
| --- | --- | --- |
| A. 선별된 식탁 | 내 안목과 일상에 어울린다. 고르고 차리는 과정이 즐겁다. | 정제된 편집, 재료의 질감, 현실적인 식사 장면. 상품·추천·사용의 완성도가 뒷받침되어야 한다. |
| B. 계절의 컬렉션 | 지금 이 계절을 가장 잘 즐기고 있다는 만족. | 실제 제철과 수확 차이, 일정한 기록 체계, 계절별 변주. 공급과 품질의 계절성이 확인되어야 한다. |
| C. 깊이 있는 원물 | 생산자의 판단과 재료를 이해하는 즐거움. | 농가의 관찰·선별·물성, 가까이 보는 사진, 간결한 설명. 생산 방식에 설득력 있는 고유 근거가 필요하다. |

### 현재의 우선순위

A를 첫 탐색 방향으로 권한다. 작물이 미정이어도 고객의 식탁과 취향이라는 관계를 먼저 설계할 수 있기 때문이다. 이후 실제 농가의 특성에 따라 B 또는 C가 주도하는 방향으로 바뀔 수 있다. 세 방향을 한 디자인에 모두 넣는 것으로 결정하지 않는다.

### 감각적 매력의 검증

상자에서 꺼내고 식탁에 놓는 장면을 보고 어떤 사람의 생활이 떠오르는가? 가격을 가린 상태에서도 갖고 싶은가? 다른 브랜드와 구분되는 단서를 말할 수 있는가? 실제 상품과 포장으로 확인하고, 선호 이유를 기능·감각·자기표현으로 나누어 기록한다.


## 18 / VERBAL PRINCIPLES

말은 짧게, 선택의 근거는 구체적으로 쓴다

말투는 전문적이되 가르치려 들지 않고, 자신감이 있되 과시하지 않으며, 친절하되 정보가 흐려지지 않게 한다.

| 상황 | 제안하는 표현 원칙 | 내부 문장 예시 |
| --- | --- | --- |
| 브랜드 소개 | 고객에게 맡는 일을 먼저 설명 | 좋은 농작물을 고르는 기준과, 잘 즐기는 방법을 전합니다. |
| 상품 소개 | 실제 선택 기준과 용도를 연결 | [확인한 특성]이 [용도]에 맞아 이번 수확에서 골랐습니다. |
| 한정 공급 | 실제 원인과 다음 기회를 설명 | 이번 출고는 [확인 수량/일정]입니다. 다음 소식은 [확정 방식]으로 안내합니다. |
| 품질 문의 | 현재 확인 내용과 다음 행동을 안내 | 보내주신 상태를 확인했습니다. [확정한 처리]를 [확정한 시점]까지 안내하겠습니다. |
| 재구매 | 고객의 판단을 돕는 이유 제시 | 지난번 [용도]를 좋아하셨다면, 이번 [상품]의 [확인한 차이]를 살펴보세요. |

### 네이밍 개발의 브리프

상위 이름은 한 작물에 갇히지 않고, 선택·식탁·생산자 태도 중 브랜드 핵심과 연결되어야 한다. 한글로 말하고 듣기 쉬우며 상품명과 함께 읽혀야 한다. 의미와 소리의 적합성, 검색 혼동, 도메인·상표 검토를 별도 단계로 수행한다.

*예시는 실제 운영 문구가 아니다. 효능·인증·시간 보증·등급·수량·개인화 기능은 확인 자료와 구현 상태가 있을 때만 반영한다.*


## 19 / TOUCHPOINT BRIEF

브랜드·디자인·개발·마케팅이 같은 기록을 사용한다

한 번 정한 표현을 모든 채널에 복사하는 것이 아니라, 각 채널이 맡는 일을 같은 브랜드 약속으로 연결한다.

| 브랜드 사이트 | 선별 근거와 농가·식사 콘텐츠의 원본 | 브랜드 소개, 상품 판단 정보, 농가 기록, 사용 안내 |

### AI 활용의 운영 원칙

AI는 확인된 정보로 문장·구성·변형안을 만드는 데 활용한다. 실제 농가·상품·인증·수확 기록은 출처가 있는 자료로 관리한다. 생성 이미지로 실제 납품 상품이나 농가의 모습을 대체해 사실처럼 제시하지 않는다.

### 개발 가이드로 이어질 항목

상품·농가·수확 배치·선별 근거·사용 안내의 데이터 소유자를 정하고, 변경 시 어떤 화면과 채널을 갱신할지 연결한다. 이미지 대체텍스트와 모바일 정보 위계를 포함한다. 구체적인 기술 스택과 플랫폼 연동은 현재 저장소와 API 확인 후 정한다.

직군은 필요한 역량을 뜻한다. 초기에는 한 사람이 여러 역할을 맡을 수 있지만, 중요한 판단의 책임은 이름으로 지정해야 한다.

*담당자·외주 여부·예산·일정은 미확정이다. 직군 목록을 채용 인원이나 계약 범위로 해석하지 않는다.*

하나씩 확정하되 앞 단계의 근거가 다음 결정을 지지하게 한다

완성도는 모든 것을 한 번에 고정해서 생기지 않는다. 다음 단계로 넘어갈 조건을 분명히 한다.

### 초기 검증의 크기

먼저 6~8명 정도의 목적 있는 인터뷰·사용 관찰로 이해되지 않는 부분을 찾는 방안을 제안한다. 이는 통계적 시장 검증이 아니다. 이후 실제 결제와 반복 배송으로 행동과 운영 재현성을 검토한다. 표본·성공 기준·예산은 실행 전 별도 합의한다.

*일정은 농가 접근성·품목·출하 시기·담당 인력에 따라 달라진다. 근거 없는 주차·비용·전환율 목표를 완료 조건으로 넣지 않았다.*


## 22 / FARM TRUTH

다음 BX 결정을 위한 첫 입력은 농가의 실제 차이다

이 질문지를 농가 대표와의 대화에 사용한다. 답을 홍보 문장으로 바로 바꾸지 말고 관찰·기록·샘플과 연결한다.

| --- | --- |

| 같은 작물 중 좋은 것을 어떻게 구별하는가? | 실물 비교와 선별 기준, 제외하는 상태의 예 |

| 공급이 부족하거나 품질이 안 맞으면 어떻게 하는가? | 대체·취소·출고 보류 등 현실적인 처리 방식 |

> 우선 필요한 네 가지: 후보 작물 / 실제 농가의 강점 / 가능한 선별·포장 수준 / 안정적인 출하 범위.

*이 입력이 확보되면 v0.2에서 고객 가설과 첫 상품의 경로를 좁히고, 네이밍과 시각 방향의 브리프를 작성한다.*

각 결정에는 결정 ID, 상태, 근거, 책임자, 변경일, 검증 조건을 붙인다. 확정·제안·검증 대기·보류를 눈에 보이게 구분하고, 외부 사례의 설명과 우리 서비스의 약속이 혼재하지 않게 한다.

### 구축과 BX의 병행

개발은 콘텐츠 구조·공통 컴포넌트·근거와 상태 표기 체계를 진행할 수 있다. 색상·로고·실제 품질 주장처럼 BX 검증에 의존하는 항목은 가변 상태로 둔다. 새 문서의 게시·배포는 기존 저장소의 승인 절차에 따라 별도 처리한다.

*이 패키지는 연구와 적용 초안이다. 기존 GitHub 저장소·배포 사이트를 수정하거나 게시하지 않았다.*
