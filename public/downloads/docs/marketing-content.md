# 콘텐츠와 AI 제작 기준

> M02 · 마케팅 · 상태: 운영 기준 · 갱신: 2026-11-10

확인된 농가 자료를 바탕으로 발굴·비교·사용·재구매 단계의 콘텐츠를 만듭니다.

## 콘텐츠가 해결할 질문

콘텐츠의 양보다 고객의 판단과 행동에 필요한 내용을 우선합니다. 생산자 이야기, 제품의 차이, 사용 안내와 이번 수확 소식을 각각 목적에 맞게 구성합니다.

| 축 | 고객의 질문 | 활용할 재료 |
| --- | --- | --- |
| 농가와 기준 | 누가 어떤 기준으로 기르는가? | 실제 인터뷰 · 재배·선별 기록 |
| 맛과 상품 | 내가 쓰려는 음식에 맞는가? | 실물 사진 · 감각 비교 · 규격 |
| 사용과 보관 | 받은 뒤 어떻게 쓰는가? | 실제 출고 상태 · 사용 관찰 |
| 수확과 반복 | 언제 다시 주문하면 되는가? | 출고 일정 · 수확 상태 · 재구매 맥락 |

## AI에 맡길 수 있는 일

AI는 확인된 자료를 요약하고 문장·구성·채널별 초안을 만드는 데 활용합니다. 입력 자료의 범위와 최종 검토자를 정하며, 사실이 추가되거나 숫자가 바뀌지 않았는지 확인합니다. 광고 성과나 콘텐츠 제작 효율은 실제 운영에서 측정합니다.

## 상품 증거를 만드는 기준

AI로 만든 사진이나 문구를 실제 농가·상품의 증거처럼 사용하지 않습니다. 존재하지 않는 인증, 생산 과정, 품질 수치, 농부의 경력과 후기를 만들지 않습니다. 시각적 설명용 이미지라면 실제 상품 사진과 역할을 구분합니다.

- 사실 자료의 원본과 사용 가능한 범위를 확인합니다.
- 작물·품종·수치·날짜·인증명은 원본과 대조합니다.
- 실제 상품의 크기·색·손질 상태가 과장되지 않았는지 확인합니다.
- 가설인 표현은 외부 홍보 문구로 자동 전환하지 않습니다.

## 제작과 검토 순서

확인된 자료 → 고객 질문 → 콘텐츠 브리프 → 초안 → 사실·표현 검토 → 채널 적용 → 결과 기록 순서로 운영합니다. 외부 게시의 담당자와 승인 기준은 별도로 정합니다. 문서에 초안을 저장한 상태와 외부 채널에 게시한 상태를 구분합니다.
