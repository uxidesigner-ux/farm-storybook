# 패키지와 상품 정보 설계

> D04 · 디자인 · 상태: 초안 · 갱신: 2026-11-10

내용물 보호, 정보의 정확성, 개봉과 사용을 연결하는 패키지 브리프 초안입니다.

## 포장은 내용물 보호에서 시작하기

실제 작물과 출고 상태에 맞는 보호·보관 조건을 먼저 확인합니다. 소재나 외관만으로 품질 보존 또는 환경적 우수성을 약속하지 않습니다. 포장에 필요한 기능과 브랜드 표현을 같은 브리프에서 검토합니다.

## 포장과 상세페이지가 공유할 정보

상품 설명, 라벨, 동봉 안내의 기준 정보를 하나로 관리합니다. 원산지·인증·보관 등 고객 판단에 필요한 항목은 실제 상품 자료를 기준으로 확정하고 적용 대상도 기록합니다.

| 정보 묶음 | 브리프 항목 | 확인 자료 |
| --- | --- | --- |
| 상품의 실체 | 작물 · 품종 · 구성 · 규격 · 출고 상태 | 농가와 상품 정의서 |
| 품질의 근거 | 선별 기준 · 인증 적용 범위 · 수확 기록 | 실제 기록과 증빙 |
| 사용 방법 | 세척 · 손질 · 보관 · 첫 사용 | 공정 확인과 실제 사용 관찰 |
| 배송과 대응 | 출고 일정 · 상태 확인 · 문의 동선 | 물류와 고객 대응 기준 |

## 실제로 판매하는 상태를 보여주기

사진은 작물의 크기·상태·분량을 오해 없이 보여줘야 합니다. 농가를 설명하는 사진과 식사 상황을 보여주는 사진을 구분합니다. 판매하지 않는 손질 상태나 존재하지 않는 재배 장면을 상품의 증거로 사용하지 않습니다.

- 상품 전체와 비교 가능한 크기 기준
- 질감과 단면을 보여주는 근접 사진
- 실제 한 번 사용하는 분량과 음식
- 검증된 재배·수확·포장 현장 기록

## 소량 시제품으로 확인할 것

대량 인쇄 전에 실제 상품을 넣고 포장·출고·개봉·보관 과정을 확인합니다. 농가의 작업 시간과 고객의 정보 이해를 함께 관찰합니다.

> **다음 결정**
> 작물·규격·배송 조건이 정해지기 전에는 포장 규격과 최종 제작 수량을 확정하지 않습니다.
