# BX 결정 기록 v0.1과 산출물 연결

> OPS05 · 운영 · 상태: 검토 중 · 갱신: 2026-11-10

브랜드·고객·품질·선별 노트·첫 작물·연동·게시의 10개 결정을 근거, 책임 역할, 검증 조건과 함께 기록합니다.

## 리서치 결과와 우리 서비스의 약속을 구분한다

기존 OPS03의 문서 상태·변경 규칙에 따라 이번 BX의 판단을 기록합니다. 리서치 완료는 명시한 조사 범위의 완료를 뜻하며 브랜드 가설이나 고객용 품질 약속의 승인을 의미하지 않습니다.

결정별 제안·검증 대기·미정·후속 단계·미실행을 유지합니다. 확정으로 바꾸려면 해당 근거와 검증 조건, 실제 책임자를 기록해야 합니다.

다음 10개 항목은 2026년 11월 10일 BX Foundation v0.1의 결정 원본을 옮긴 것입니다. 자료의 게시와 사업·품질 결정의 확정은 별도로 관리합니다.

> **검토안의 공개와 운영 약속**
> Storybook에서 이 초안을 공유하더라도 상품·브랜드·가격·품질·기능이 확정되는 것은 아닙니다. 소비자 문구는 실제 제공 범위와 책임자가 확인된 뒤 별도로 확정합니다.

## BX-006~010: 경험·작물·표현·연동·게시

선별 노트, 첫 작물, 네이밍·CI와 플랫폼 연동은 실제 자료와 구현 상태를 확인한 뒤 결정합니다. 아직 실행하지 않은 작업을 완료로 표시하지 않습니다.

BX-010의 게시 미실행은 보고서 원본 작성 시점의 기록입니다. 이번 Storybook 업데이트의 구현·검증·원격 반영·배포 결과는 실제 작업 결과와 승인 범위를 확인해 후속 변경 이력으로 남깁니다.

## 결정마다 남길 최소 정보

결정 ID는 유지하고 상태, 근거, 책임자, 변경일, 검증 조건을 함께 기록합니다. 의견이 바뀌면 이전 판단을 지우기보다 무엇을 어떤 근거로 변경했는지 남깁니다.

| 기록 항목 | 작성 내용 |
| --- | --- |
| ID·주제 | 한 번 정한 결정 식별자와 다루는 질문 |
| 상태·제안 | 확정·제안·검증 대기·보류 등 현재 상태와 구체적인 내용 |
| 근거 | 공식 출처, 농가 기록, 샘플·사용 관찰, 구현·운영 확인 자료 |
| 책임자 | 필요 역량의 역할과 실제 담당자; 미정이면 미정으로 표시 |
| 변경일·변경 이유 | 언제 어떤 판단을 왜 바꾸었는지 |
| 검증·다음 조건 | 어떤 증거가 있어야 확정하거나 다음 단계로 넘어가는지 |

## 구축과 BX를 병행하는 방식

개발은 콘텐츠 구조·공통 컴포넌트·출처·상태 표기 체계를 진행할 수 있습니다. 색상·로고·실제 품질 주장처럼 BX 검증에 의존하는 항목은 가변 상태로 둡니다.

공유된 문서 ID와 기존 출처를 보존하고, 새 문서의 게시·원격 반영·배포는 저장소 규칙과 확인된 사용자 승인 범위에 따라 처리합니다. 문서 수정, 로컬 검증, 원격 반영, 외부 배포를 각각의 실행 결과로 기록합니다.

구체적인 연동 기술과 운영 책임은 현재 저장소와 API·권한을 확인한 뒤 정합니다. 연결되지 않은 기능이나 아직 확인하지 않은 공개 URL을 완료 사실로 보고하지 않습니다.
