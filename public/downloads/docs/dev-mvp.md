# MVP 범위와 기능 정의

> DEV01 · 개발 · 상태: 검토 중 · 갱신: 2026-11-10

브랜드 소개·구매·운영에 필요한 기능을 구분하고, 확정되지 않은 거래 방식을 명시합니다.

## 현재 사업 구상

농가와의 협의, 농가 패키징, 브랜드 사이트, 스마트스토어 등 판매 채널, AI를 활용한 마케팅 제작이 초기 구상입니다. 이 문서는 기존 구상을 개발 검토가 가능한 단위로 정리한 초안입니다. 자체 결제·외부 구매 연결·채널 간 자동 연동은 아직 확정된 구현 범위가 아닙니다.

## 기능군과 필요한 결정

고객에게 보이는 기능과 운영자가 유지해야 하는 기능을 함께 정의합니다.

| 기능군 | 초기 검토 항목 | 선행 결정 |
| --- | --- | --- |
| 브랜드 소개 | 농가 · 핵심 약속 · 근거 자료 | 포지셔닝과 공개 가능한 사실 |
| 상품 탐색 | 목록 · 상세 · 규격 · 용도 · 배송 정보 | 대표 상품과 옵션 구조 |
| 구매 | 외부 구매 연결 또는 자체 주문 | 거래 채널 · 결제 · 운영 책임 |
| 운영 | 상품 상태 · 출고 안내 · 문의 대응 | 담당자 · 변경 기준 · 실제 업무 흐름 |
| 측정 | 상품 조회 · 구매 이동 · 문의 | 측정 범위와 실제 확인 가능한 데이터 |

## 초기에 판단을 보류할 기능

정기구독, 다채널 통합 재고, 개인화 추천과 복잡한 회원 체계는 수요와 운영 필요가 확인된 뒤 검토합니다. 구독이 브랜드의 필수 조건이라는 전제를 두지 않습니다. 반대로 필요한 변경·품절·문제 대응 안내는 작은 범위에서도 누락하지 않습니다.

## 기능 정의의 필수 항목

개발 요청에는 화면 이름만 적지 않고 어떤 조건에서 어떤 결과가 나와야 하는지 씁니다.

- 목적과 이용자, 진입 조건
- 정상 흐름과 완료 상태
- 입력값·노출값·데이터 출처
- 품절·오류·권한·빈 상태의 처리
- 관련 정책과 미확정 결정, 확인 담당 직군
