# 선택부터 식탁까지의 경험과 선별 노트

> B07 · BX · 상태: 초안 · 갱신: 2026-11-10

구매 전 확신, 수령 후 사용, 문제 해결을 하나의 약속으로 연결하고 선별 노트의 정보·운영 구조를 검토합니다.

## 고객이 느낄 감정과 제공할 행동을 연결한다

이 문서는 기존 B04 고객 경험 원칙을 구체화한 설계안입니다. 구매 때의 확신, 받을 때의 정돈감, 먹을 때의 만족, 문제가 생겼을 때의 신뢰가 이어지는지 검증합니다.

품격에는 정돈된 정보와 책임 있는 서비스뿐 아니라 고르고 차리고 즐기는 순간의 감각적 만족이 포함됩니다. 편리하다고 느끼는 이유와 이 브랜드를 갖고 싶어 하는 이유를 각각 확인합니다.

> **제안과 현재 기능을 구분**
> 아래 행동·알림·개인화·처리 시간은 목표 경험입니다. 제공 범위와 담당자, 운영 정책과 구현 상태가 확인되기 전에는 소비자에게 제공 중인 기능으로 안내하지 않습니다.

## 발견·비교·주문·수령 전의 경험

이번에 제안하는 상품과 추천 이유를 먼저 보여주고 자세한 농가 이야기와 기준으로 이어지도록 합니다. 상품 비교와 주문에 필요한 정보는 브랜드 서사나 영상 속에 숨기지 않습니다.

- 고객이 이 상품을 고른 이유를 자기 말로 설명하는지 확인합니다.
- 적정 사용량과 손질 상태를 이해하는지 관찰합니다.
- 가격·출고 조건을 놓치지 않는지 실제 탐색 행동으로 확인합니다.

| 접점 | 고객이 느낄 것 | 제안하는 행동·정보 |
| --- | --- | --- |
| 첫 발견 | 이 브랜드는 고르는 기준이 있구나 | 실제 상품과 식사 장면에 구체적인 선별 이유 하나를 붙인다. |
| 브랜드 이해 | 누가 어떤 판단을 하는지 알겠다 | 농가의 생산 지식, 선별 방식, 브랜드가 맡는 일을 분리해 설명한다. |
| 상품 비교 | 내 식사에 맞는 선택이다 | 품목·양·손질 상태·맛/식감·용도·가격·일정을 비교 가능하게 둔다. |
| 주문 | 무엇을 언제 받는지 분명하다 | 실제 판매 옵션과 출고 조건, 변경 가능 범위를 확정 정보로 보여준다. |
| 수령 전 | 준비 과정이 예측 가능하다 | 확인된 출고 상태와 필요한 보관 준비를 짧게 알린다. |

## 개봉·보관·식사·문제 해결·재구매

받은 순간의 인상뿐 아니라 보관하고 먹고 문제를 해결하는 경험에서 반복 구매의 이유를 확인합니다. 보관 방식과 안내는 실제 품목의 특성에 맞춰 정합니다.

장식 때문에 상태를 확인하기 어렵거나 보관 설명이 QR 안에만 있거나 문의할 때마다 답이 달라지는 상황은 신뢰를 약하게 만들 수 있다는 설계 가설로 검토합니다.

| 접점 | 고객이 느낄 것 | 제안하는 행동·정보 |
| --- | --- | --- |
| 개봉 | 차분하고 세심하게 준비됐구나 | 상품을 손상 없이 꺼낼 수 있고 구성과 상태를 한눈에 확인한다. |
| 보관 | 받은 뒤 무엇을 할지 안다 | 제품과 함께 바로 읽을 수 있는 보관·사용 안내를 둔다. |
| 손질·식사 | 내 일상에서 차이가 느껴진다 | 검증한 먹는 방법을 최소한의 단계로 안내한다. |
| 문제 발생 | 이 브랜드가 책임지고 있구나 | 문의 이력을 이어 받고 다음 처리 단계와 시간을 명확히 안내한다. |
| 재구매 | 내 취향을 이해하고 다음 선택을 돕는다 | 지난 선택의 용도와 피드백을 바탕으로 실제 판매 가능한 제안을 한다. |

## 선별 노트: 선택의 이유와 잘 즐기는 방법

선별 노트를 첫 고유 경험의 후보로 제안합니다. 기록 형식 자체가 독자적인 경쟁력으로 확인된 것은 아닙니다. 실제 상품의 차이를 짧고 일정한 구조로 전달하는 장치입니다.

기록 단위는 품목·농가·출고 운영을 확인한 뒤 정합니다. 수확별 기록은 지속적으로 차이를 확인하고 관리할 수 있을 때 도입합니다. 먼저 후보 작물에 가안 적용해 이해도·작성 부담·정보 유지 가능성을 확인합니다.

| 앞면의 핵심 정보 | 작성 규칙 |
| --- | --- |
| 무엇인가 | 확정된 품목·품종·규격. 익숙한 이름과 설명을 우선한다. |
| 누가 길렀는가 | 확인된 농가·지역과 생산자가 공개에 동의한 내용. |
| 언제의 기록인가 | 수확·포장·출고를 혼동하지 않고 실제 확인 날짜를 쓴다. |
| 왜 골랐는가 | 해당 배치에서 확인한 선택 이유 한 문장. 근거 없는 최상급은 제외한다. |
| 어떻게 즐기는가 | 검증한 보관·손질·사용 안내를 짧게 제공한다. |

> **첫 템플릿의 범위**
> 확인 가능한 정보만 채웁니다. 선별 노트의 날짜가 수확일인지 포장일인지 출고일인지 분명히 표시하고, 아직 확인하지 않은 항목은 사실처럼 작성하지 않습니다.

## 내부 문장 템플릿과 기록의 연결

내부 예시: “이번 [품목]은 [용도]에 맞는 [확인한 특성]을 기준으로 골랐습니다. [검증한 사용 방법]으로 즐겨보세요.” 대괄호는 실제 자료로 채우기 전까지 내부 초안에서만 사용합니다.

라벨·상품 상세·출고 안내가 같은 기록을 참조하도록 설계합니다. 상세 이력은 링크로 확장하되 기본 보관과 상품 식별 정보는 제품 표면 또는 동봉 안내에서 바로 읽을 수 있게 합니다.

맛 점수, 등급, 배치 번호는 실제 기준과 관리 체계가 있을 때만 도입합니다. 기록 책임자와 수정 시 갱신해야 할 채널을 함께 정합니다.

## 패키지·브랜드 사이트·판매 채널·Storybook의 역할

각 채널이 맡는 일을 같은 브랜드 약속으로 연결합니다. 고객에게 설명할 원본 정보와 거래 채널의 옵션·가격·주문·배송 정보는 서로 일치해야 합니다.

플랫폼 결제·재고·배송의 자동 연동은 완료된 기능이 아닙니다. 실제 API와 권한, 운영 범위는 개발 가이드에서 별도로 확인합니다.

| 영역 | 초기 역할 | 필요한 산출물 |
| --- | --- | --- |
| 패키징 | 상품 보호, 구성 확인, 보관 전환 | 구조 시제품, 실제 부착 라벨, 선별 노트, 포장 작업 가이드 |
| 브랜드 사이트 | 선별 근거와 농가·식사 콘텐츠의 원본 | 브랜드 소개, 상품 판단 정보, 농가 기록, 사용 안내 |
| 거래 채널 | 정확한 옵션·가격·주문·배송 정보 | 상품 정보 기준표, 재고·옵션 관리 책임, 구매 후 안내 |
| Storybook | 팀과 사용자가 공유할 기준과 근거 | BX 연구, 의사결정 기록, 디자인 원칙, 개발·마케팅 가이드 |
| 마케팅 | 선택의 이유를 이해하고 사용하도록 도움 | 선별 근거·농가 판단·식사 활용의 콘텐츠 시리즈 |

## 사용 관찰과 다음 개선 기록

개봉과 손질에 걸리는 시간, 품질 만족, 불편 발생, 재구매 이유를 관찰합니다. 수치 목표나 보관 가능 기간은 품목과 실제 근거 없이 정하지 않습니다.

고객의 기능적 편익, 감각적 만족, 취향 표현을 나누어 기록합니다. 질문에 대한 말뿐 아니라 실물·포장·안내를 사용하는 행동을 함께 봅니다.

농가·상품·선별 근거·사용 안내의 데이터 소유자와 갱신 경로를 정하고, 이미지 대체텍스트와 모바일의 정보 우선순위를 포함합니다. 확인된 문제를 OPS05 결정 기록에 연결합니다.
