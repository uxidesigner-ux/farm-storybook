# 농가의 사실을 확인하는 인터뷰와 기록 양식


## 목적

브랜드의 주장보다 먼저 생산·선별·포장·공급에서 반복 가능한 차이를 확인한다. 미확인 답변은 가설로 남긴다.


## 인터뷰 질문

| 질문 | 받을 자료 또는 관찰 |
| --- | --- |
| 무엇을, 언제, 어느 정도 생산할 수 있는가? | 작물·품종 목록, 계절별 출하 범위, 일정 변동 요인 |
| 같은 작물 중 좋은 것을 어떻게 구별하는가? | 실물 비교와 선별 기준, 제외하는 상태의 예 |
| 그 차이는 고객의 어느 식사에서 드러나는가? | 생식·가열 등 사용 비교, 농가의 추천 이유 |
| 누가 선별하고 어떤 기록을 남기는가? | 작업 흐름, 담당자, 반복 가능한 기록 방식 |
| 현재 어디까지 손질·포장할 수 있는가? | 작업대·재료·도구·소요 시간·포장 샘플 |
| 배송 이후 상태는 어떻게 달라지는가? | 실제 배송 관찰과 손상·변화 이력 |
| 브랜드가 공개해도 되는 생산 정보는 무엇인가? | 농가 동의 범위, 확인 가능한 자료 |
| 공급이 부족하거나 품질이 안 맞으면 어떻게 하는가? | 대체·취소·출고 보류 등 현실적인 처리 방식 |


## 한 주장당 기록할 항목

| 항목 | 기입 내용 |
| --- | --- |
| 진술 | 농가가 설명한 사실이나 가설 |
| 증거 | 실물 샘플·작업 관찰·기록·사진 등 |
| 확인자와 날짜 | 누가 언제 확인했는가 |
| 반복성 | 다른 출하·계절·작업자에게도 유지되는가 |
| 고객의 쓰임 | 어떤 식사·취향·수고에 차이를 만드는가 |
| 공개 가능성 | 공개 가능한 사실과 동의 범위 |
| 다음 검증 | 추가 확인 방법과 책임자 |


## 첫 워크숍의 출력


- 후보 작물과 출하 가능 범위
- 실제 선별·포장의 가능 수준
- 고객에게 체감될 차이 후보
- 확인이 끝난 사실과 아직 가설인 문장
- 첫 상품 경로 선택의 근거


기준 숫자, 인증, 효능, 보관 기간, 배송 시간은 확인 자료 없이 채우지 않는다. 이 인터뷰 양식은 법정 표시나 식품 안전 검증을 대체하는 서류로 설계한 것이 아니다.
