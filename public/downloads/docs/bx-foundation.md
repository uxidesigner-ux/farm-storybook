# 브랜드 정의 v0.1과 다섯 키워드

> B06 · BX · 상태: 검토 중 · 갱신: 2026-11-10

최상의 퀄리티·품격·유니크·차별화·선택받은을 제품 기준, 고객 태도, 표현 자산과 선택 이유로 구체화하는 검토안입니다.

## 선별의 기준이, 일상의 취향이 되다

브랜드의 역할을 좋은 농작물을 고르는 판단과 선택한 농작물을 잘 즐기는 방법을 함께 제공하는 서비스로 제안합니다. 특정 작물의 형태보다 선별·취급·사용을 책임지는 태도를 중심에 둡니다.

확장 가능한 마스터브랜드와 좁은 첫 상품 제안을 함께 검토합니다. 치커리·셀러리 등 한 작물에 이름을 묶지 않되 출시 때에는 누구의 어떤 식사 상황을 해결할지 먼저 좁힙니다.

이 문서의 고객 행동, 품질 약속, 표현 방향은 검증할 제안입니다. 실제 제공 범위와 책임자가 확정되기 전에는 소비자용 운영 약속으로 사용하지 않습니다.

> **현재 상태**
> 전략 초안 v0.1입니다. 품목·품종·타깃·가격·브랜드명·로고·인증·공급 능력·품질 기준은 미확정입니다. 핵심 문장은 광고 슬로건의 최종안이 아닙니다.

## 다섯 키워드에 서로 다른 역할을 부여한다

다섯 표현을 같은 층위의 핵심 가치로 나열하면 실제 판단 기준이 흐려집니다. 퀄리티는 제품과 운영의 기준, 품격은 고객을 대하는 태도, 유니크는 식별 자산, 차별화는 대안 대비 선택 이유, 선택받은은 상품과 고객의 감정으로 나누어 검토합니다.

선택받은의 가설은 기준으로 고른 상품 → 이유를 이해하는 고객 → 좋은 선택을 했다는 만족입니다. 공급이 실제 수확량·품질 조건 때문에 제한된다면 그 이유와 다음 기회를 명확히 설명합니다.

| 키워드 | 전략상 역할 | 고객이 확인할 경험 |
| --- | --- | --- |
| 최상의 퀄리티 | 제품과 운영이 지향할 기준 | 선별 기준, 실제 상태, 취급 기록, 반복되는 도착 품질 |
| 품격 | 고객을 대하는 태도 | 정돈된 정보, 쉬운 개봉·보관, 차분하고 책임 있는 응대 |
| 유니크 | 브랜드를 알아보게 하는 자산 | 농가의 실제 단서에서 나온 고유한 언어·사진·정보 규칙 |
| 차별화 | 대안 대비 고객의 선택 결과 | 왜 더 지불하거나 다시 선택하는지 설명되는 차이 |
| 선택받은 | 상품의 상태와 고객의 감정 | 기준을 통과한 농작물, 내 취향과 판단을 존중받는 느낌 |

> **최상의 퀄리티는 내부 지향점**
> 비교 범위와 근거가 없는 절대적 우월 주장이나 아직 확인하지 않은 품질 보증 문구로 사용하지 않습니다.

## 브랜드의 존재 이유·역할·고객 가설

다음 정의는 농가와 고객 검증을 시작하기 위한 작업 가설입니다. 정서적으로는 내 선택에 기준이 있다는 확신과, 내게 어울리는 식탁을 제안받고 취향이 섬세하게 드러나는 경험을 목표로 검토합니다.

- 기준 있게 고릅니다.
- 차이를 이해하게 합니다.
- 식탁에서의 사용까지 배려합니다.
- 세 실행 가치는 농가·포장·콘텐츠·고객 응대의 행동과 책임으로 각각 번역합니다.

| 항목 | 작업 정의 |
| --- | --- |
| 존재 이유 | 좋은 먹거리를 고르는 판단과 준비의 수고를 덜어, 만족스러운 식사를 돕는다. |
| 초기 고객 가설 | 먹는 질을 중시하고, 선택 이유를 이해하고 싶지만 매번 비교·준비할 시간은 부족한 사람. |
| 고객 긴장 가설 | 좋다는 설명은 많지만, 내 식사에 맞는 이유와 받아서 잘 쓸 방법은 불분명하다. |
| 브랜드 역할 | 농가의 생산 지식과 고객의 식탁을 연결하는 선별자이자 안내자. |
| 핵심 생각 | 선별의 기준이, 일상의 취향이 되다. |
| 기능적 이익 | 이유가 분명한 선택, 이해하기 쉬운 사용 안내, 예측 가능한 수령 경험. |
| 정서적 이익 | 내 선택에는 기준이 있다는 확신, 내게 어울리는 식탁을 제안받고 내 취향이 섬세하게 드러나는 느낌. |
| 성격 | 정확한 안목 / 절제된 자신감 / 세심한 배려. |
| 증명 수단 | 품목별 선별 기준, 농가의 실제 기록, 보관·사용 실험, 배송 확인, 문제 해결 이력. |

## 첫 상품의 강점으로 앞세울 경험을 고른다

미각의 발견, 정돈된 식사, 계절의 선택은 첫 상품의 중심 약속을 고르기 위한 세 경로입니다. B02의 기존 포지셔닝 가설을 이번 BX 정의에 연결한 것이며, 표현 시안을 비교하는 B08의 세 콘셉트와는 구분합니다.

설명 가능한 선별은 신뢰의 공통 요건으로 둡니다. 차별화는 구체적인 식사 상황에서 농가가 반복해서 제공할 수 있는 강점이 만드는 체감 차이로 결정합니다. 첫 상품에는 한 경로를 우선하고 맛·편의·희소성의 검증 범위를 정합니다.

| 경로 | 선택 조건 | 첫 고객 경험 |
| --- | --- | --- |
| 미각의 발견 | 품종·재배·수확 판단에서 체감할 맛·식감 차이를 반복 확인할 수 있다. | 무엇이 다른지 설명하고, 차이가 드러나는 먹는 방법을 제공한다. |
| 정돈된 식사 | 규격·손질·포장·출고 일정이 안정적이고 고객의 실제 수고를 줄일 수 있다. | 내 식사에 맞는 양과 준비 상태를 쉽게 고른다. |
| 계절의 선택 | 특정 시기의 품질은 좋지만 수량과 공급 기간이 제한적이다. | 출고 가능 시기·수량·선별 이유와 다음 수확을 이해한다. |

## 상위 브랜드와 실제 상품 정보를 나눈다

마스터브랜드는 선별과 식탁 경험의 역할을 담고, 상품은 작물·품종·규격·손질 상태를 설명합니다. 상품군과 기록 단위는 실제 공급·판매·출고 운영을 확인한 뒤 정합니다.

아래 수확 배치는 향후 검토할 정보 계층입니다. 수확별 기록과 번호 체계를 현재 운영 중인 기능으로 전제하지 않습니다. 첫 상품의 약속과 품질 재현성을 먼저 확인합니다.

| 정보 계층 | 지금 정할 것 | 나중에 채울 것 |
| --- | --- | --- |
| 마스터브랜드 | 선별과 식탁의 경험을 책임지는 역할 | 이름·상표·로고 |
| 상품군 | 고객의 용도와 선택 방식 | 생식·가열·반찬 등 실제 분류 |
| 상품 | 품종·규격·손질 상태 | 첫 작물과 판매 옵션 |
| 수확 배치 | 실제 기록과 정보 갱신 책임 | 농가·수확일·포장일·확인 결과 |

## 보기 좋은 인상과 선택 이유를 각각 검증한다

고객에게 상품명과 디자인을 가린 상태에서 품질과 사용의 차이를 설명하게 하고, 이후 정보·포장·가격을 제시해 선택 이유가 어떻게 달라지는지 확인하는 방법을 제안합니다. 호감, 구매 이유, 재구매 이유를 분리해 기록합니다.

기본적인 품질 충족과 브랜드만의 선별 취향도 구분합니다. 도착 상태의 기준과 특정 요리에 맞는 식감은 서로 다른 판단입니다. 품질 기준·측정법·책임자·예외 처리가 정해진 뒤 고객 문구를 확정합니다.

실제 타깃 세그먼트와 지불 의사 결과는 아직 없습니다. 농가 자료와 품질 증거의 구체적인 확인 항목은 OPS04에서 관리합니다.

> **차별화의 작업 문장**
> 우리는 [구체적인 식사 상황의 고객]에게 [농가가 반복해서 제공할 강점]으로 [고객이 체감할 차이]를 제공한다. 대괄호는 실물과 사용자 근거가 확보될 때 채웁니다.
